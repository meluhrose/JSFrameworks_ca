<h1>JavaScript Frameworks: Online Shop</h1>

<h2>Overview</h2>

A responsive  e-commerce style application built with Next.js, React, TypeScript and TailwindCSS for my JavaScript Frameworks course assignment. Online Shop demonstrates core concepts from JavaScript Framweworks, including routing, dynamic pages, client/server components, state management, and API/data handling.


<h2>Built With🛠</h2>

- Next.js
- React
- TypeScript
- TailwindCSS
- REST API
- Headless UI
- Sonner


<h2>Features✨</h2>

<h3>Product Listing</h3>

- Displays products in a responsive grid
- Shows title, image, rating, description, price, and discount price if available.
- Discount badge with automatic percentage calculation

<h3>Product Details Page</h3>

- Dynamic route: /products/[id]
- Shows full product information and reviews.
- Add product to the shopping cart.

<h3>Search Bar and Sorting</h3>

- Search by titles and tags
- Sort products by:
    
    - Default
    - Price: Low to High
    - Price: High to Low
    - Rating: High to Low

<h3>Cart Page</h3>

- Increase and decrease quantity
- Remove items from the cart
- Displays total cost and item count
- Check out button directs to a successful page.

<h2>Installation and Setup</h2>

Make sure your have Node.js and npm installed.

<h3>Clone the repository</h3>

```bash
git clone https://github.com/meluhrose/JSFrameworks_ca.git
cd JSFrameworks_ca
```

<h3>Install dependencies</h3>

```bash
npm install
```


<h3>Run the development server</h3>

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the application.
